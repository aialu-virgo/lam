Performance Desk on Google Apps Script

Set up once as ai.acp@virgoasia.com (or data@virgoasia.com). Every Virgo Google user can then open the Desk at your own link, with no claude.ai account. About 10 minutes, plus the data move.

Cutover rule: from the moment you download the backup (step 8) until the restore shows every section "ok", nobody uploads or edits on the claude.ai Desk.

  1. Create the project

    Open script.google.com › New project signed in as ai.acp@virgoasia.com. Name it Virgo Desk.

  2. Settings file

    Project Settings (gear) › tick Show "appsscript.json" manifest file in editor. Open appsscript.json, select all, paste:

    appsscript.json

  3. Server code

    Open Code.gs, select all, paste:

    Code.gs

  4. The Desk page

    + › HTML, name it exactly Index. Select all, paste (about 1.4 MB, the editor may take a minute), then Save:

    Index.html

  5. Run setup

    In the toolbar choose the function setup and press Run. Allow the permissions (Google Sheets and your email address). This creates the spreadsheet "Virgo Desk database (do not edit)" in your Drive.

  6. Deploy

    Deploy › New deployment › Web app. Execute as: Me. Who has access: Anyone within virgoasia.com. Deploy, then copy the Web app URL (ends in /exec). That is the link for all users. Send it to the Delivery Lead.

  7. Open it

    Open the /exec link yourself. You are a Super admin, so Admin is available.

  8. Download the backup

    On the claude.ai Desk: Admin › Tools › Download full backup, then save all files to your computer. If the page says data changed during the backup, run it again.

  9. Restore

    On the new Desk: Admin › Tools › Restore from backup, select all the backup files together. Keep the tab open until every section shows "ok". If it says "Restore incomplete", tick Replace everything and run it again.

  10. Check and share

    Admin › Tools › Measure store size confirms what loaded. Then share the /exec link with users who are in Admin › Users.

Later versions: paste the new Index file, then Deploy › Manage deployments › pencil › Version: New version › Deploy. The link stays the same.
