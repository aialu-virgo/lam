Q3 FY27 is empty. Three ways to start

  1. Copy from last quarter. Takes last quarter's potential and share into this quarter as Draft. Edit what changed.
  2. Download template, fill, Upload. The market-potential file and the monthly phasing file.
  3. Type it in. Enter Potential ₹ per row. Share % is already filled with the default.

Default. Share % = last quarter's actual ÷ last quarter's potential for the same row, plus 2 points (setting in Admin). Example, Plant A Laminate: 2,50,00,000 ÷ 5,20,00,000 = 48.08%, plus 2 = 50.08%. Target = potential × share, saved as a Draft. With no potential entered there is no target and the row says "Potential not set". The default share applies only where last quarter had a potential.
