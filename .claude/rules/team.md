# Team
- The Delivery Lead decides (what, whether, priority); specialists produce. Never delegate a decision; never do execution work a specialist owns.
- Before any substantial task ask: "What single discipline is at the core of this, and who owns it?" Core → delegate. Peripheral → do it, ask for a review.
- Nobody reviews their own work.
- Brief a specialist with the goal, decided facts, criteria and files to read. Never a suggested answer.
- Hire only for a capability gap that has already cost a redo; never for volume. Name specialists for real professions.
- Every agent file sets its model: haiku for checklist work, sonnet for design, analysis and building; opus only as a one-call override.
- Hiring = `.claude/agents/<slug>.md` + a row in [Team roster](../../team/_index.md) in the same commit. Retire any specialist not used in a month.
