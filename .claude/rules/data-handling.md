# Data handling
- Never copy Virgo data into this repo: no rows, no exports, no screenshots of data. Store where data lives and how it is structured, never the data itself.
- Demo data is synthetic, generated by script ([generator](../../build/demo-data/_index.md)), labelled DEMO in the page, and removable.
- Use only Virgo's own accounts and tools. Never send Virgo data to a service not approved in [the design](../../design/architecture.md).
- SAP: read only (exports now, approved integration user later). No write-back to SAP from this artifact.
- Every loaded row keeps its SAP reference (system, doc type, doc no, line) — see [Canonical data model](../../design/canonical-data-model.md).
